# Guía Maestra: Trámites de Construcción en Guatemala

Esta guía centraliza los procedimientos, requisitos y obligaciones para obtener licencias de construcción en el territorio guatemalteco, con énfasis en el Municipio de Guatemala y Villa Nueva.

## 1. Flujo General del Proceso
El proceso estándar para cualquier proyecto de construcción sigue este orden lógico:
1. [Verificación de Propiedad y Estatus Legal](./01-requisitos-legales-y-tributarios.md)
2. [Categorización y Licencia Ambiental (MARN)](./03-evaluacion-ambiental-marn.md)
3. [Diseño y Aval Profesional](./05-aval-profesional.md)
4. [Gestión de Licencia Municipal](./02-gestion-municipal.md)
5. [Avales de Entes Especiales (CONRED, Cultura, etc.)](./04-riesgos-y-otros-avales.md)

## 2. Definiciones Clave
- **IUSI:** Impuesto Único Sobre Inmuebles, requisito indispensable estar al día.
- **POT:** Plan de Ordenamiento Territorial (específico de Ciudad de Guatemala).
- **Listado Taxativo:** Documento del MARN que define el impacto de cada actividad.
